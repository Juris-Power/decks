# Les présentations de Juris-Connect

Chaque dossier est un deck, construit par le moteur de présentation du dépôt principal et publié par
`bash scripts/publier-deck.sh <slug>` — sans passer par le déploiement de l'application.

Le lien d'un deck : `https://juris-power.github.io/decks/<slug>/`.

Ne pas éditer à la main : tout fichier ici est le produit d'un build, et le prochain le remplace.
