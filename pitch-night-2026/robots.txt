# Ils passaient deja par le `User-agent: *` ci-dessus. Ce qui change, c'est que
# les autoriser devient une DECISION ecrite plutot qu'un effet de bord : la
# prochaine session qui se demandera « faut-il les bloquer ? » trouvera la
# reponse et son motif, au lieu d'un silence.
#
# Le motif : le Q/R public a perdu ~99 % de son volume depuis 2022, et les
# archives de ce type sont devenues moins des destinations que des corpus que
# les assistants font remonter. On ne peut pas empecher un modele de repondre a
# notre place ; la seule contrepartie disponible est d'etre la source NOMMEE —
# un avocat identifie qui remonte dans la reponse vaut mieux qu'un contenu
# anonyme absorbe. Sources : documentation/roadmap/forum-connect-best-in-class/
#   09-etat-de-lart-et-sources.md
#
